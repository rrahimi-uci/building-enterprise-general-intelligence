# C10 — Bounded ReAct checkpoint

Run: `python -m mortgage_case --chapter 10 --scenario happy_path --offline`

Before: adaptive evidence work has no external loop bound. Added: an offline
acceptance check that compares deterministic observations and recorded turn,
tool-call, cost, and elapsed-time usage against a budget. It refuses an
over-budget fixture after its observations have been produced. It does not
meter provider calls or interrupt live execution; a production adapter must
gate each invocation using its own trusted usage meter.
`repeated_observation`, `turn_budget_exceeded`, `tool_budget_exceeded`,
`cost_budget_exceeded`, and `time_budget_exceeded` are deterministic refusal
scenarios. On provider outage, the partial observation is retained in a
structured `needs_input` report with its evidence reference.
