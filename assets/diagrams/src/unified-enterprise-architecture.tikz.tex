% Final synthesis -- one book-level architecture, derived from Chapters 1--28.
% Element map: Ch 4 seven ownership planes are consolidated into four visual
% zones: global control, regional runtime, external systems, and improvement.
% Security/governance is a cross-cutting service band, not a step in the model
% loop. The typed request/proposal/effect path follows Ch 2--4 and 13--22;
% the separate knowledge release path follows Ch 5--6; evidence and release
% feedback follow Ch 24--27. The long return edge moves a reviewed release,
% never a live model-generated change.
%
% Visual polish (content unchanged): every node, label, edge, line style,
% pill and key entry is kept. Presentation only -- zone titles become filled
% header tabs with an icon (replacing the thin title rules); each card carries
% a role-coloured icon before its title and the house soft shadow; the grid is
% regularised; and edges that crowded cards or frame borders run through clear
% corridors (Run pin enters Run and workflow from above, Receipt / outcome and
% Knowledge pin use side corridors, runtime evidence passes left of the
% improvement title, and the release return runs outside the frames). The key
% sits in its own panel.
