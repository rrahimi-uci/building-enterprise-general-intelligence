# Content observations, group b1 (raised, not changed)

Technical doubts noticed while restyling `causal-trace`, `context-pipeline`, `document-ingestion`, `evaluation-gate` and `identity-delegation`. The restyled figures keep the original semantics exactly; none of these was acted on.

1. **`causal-trace` (Figure 24-1): the dashed "queue / resume" edge skips Retrieval, Model turn and Policy decision.** It runs from Workflow task straight to Tool / remote task. Read as control flow, it suggests that a resumed task reaches the tool without a policy decision. If it is meant as a causal link (a span link across a queue), the figure does not say so, and the solid run path and the dashed link use the same arrowhead. Kept as in the source.
2. **`causal-trace`: Accepted outcome has no evidence edge.** Eight dotted edges go to the three stores, but the last step ("user + business record") writes to none of them, while "Effect outcome" writes to the audit ledger. Possibly intended (the effect receipt is what is audited); noted only because the caption says the ledger "proves protected decisions and effects".
3. **`context-pipeline` (Figure 6-1): "4 . Fetch pinned versions" precedes "9 . Ordered references: references only, no content yet".** The annotation on "model request" says it is "the only boundary that materializes bytes", yet stage 4 reads as fetching content, which is before the "references only" annotation. If stage 4 fetches pinned version identifiers (references) rather than bytes, the label could say so. Kept as in the source.
4. **`document-ingestion` (Figure 5-3): the red edge from the verify diamond is "contradicted or insufficient", while the terminal box says "contradicted or unverifiable".** "Insufficient" and "unverifiable" are probably the same state seen from two sides, but the two words differ, and the repair loop ("repair one field") is only reachable through "insufficient". Kept as in the source.
5. **`document-ingestion`: the dotted "re-opens the pinned bytes" edge ends at the source document, while the label on the first edge says only "bytes".** Consistent with the message ("verification re-opens the bytes"), but the figure never says that the re-open path is read-only; the dotted style carries that meaning only by convention.
6. **`evaluation-gate` (Figure 25-1): the "privacy-reviewed" label sits on Block release > Review and reduce, not on the edge back into the immutable dataset.** The privacy review is a precondition of a case entering the dataset, so it reads more naturally on "future regression" (case > dataset). As drawn, a block is privacy-reviewed before the case is reduced. Kept as in the source.
7. **`evaluation-gate`: "residual risk" leads to a waiver, "fail" blocks directly, and a denied waiver also blocks.** A waiver that expires ("approved + expires") returns to the same Promote node, with no edge back to the gate when the waiver lapses. Possibly out of scope for the figure.
8. **`identity-delegation` (Figure 21-1): `inventory.md` calls the re-check edge a "dotted re-check loop"; the source draws it dashed (amber).** The restyle follows the source (dashed). The inventory entry is wrong, not the figure.
9. **`identity-delegation`: dashed and solid edges mix delegation and credential flow.** "delegate" (Platform agent > Child grant) is dashed while "subset only" (Child grant > Specialist agent) is solid, and "approved scope" / "short-lived lease" are dashed while "last-hop credential" is solid. The figure has no legend for dashed, so a reader cannot tell policy control from credential movement. Kept as in the source.

## Judgement calls (layout and typography only)

- `evaluation-gate`: the three inputs are drawn in the order candidate, baseline, dataset (the source order is dataset, candidate, baseline) so the dashed regression edge reaches the dataset along the right margin instead of crossing the figure.
- `causal-trace`: the Trace index sits on the left of the run, the Content vault and Audit ledger on the right; the original had all three on the right. Every edge keeps its source and target.
- Lowercase labels became sentence case ("Queue / resume", "Model request", "Before a single byte is fetched"). The dash in "references only, no content yet" is kept as an em dash.
- `context-pipeline`: the numbers 1 to 10 are round badges at the left of each card (the source writes "1 . Parse request"); the words are the card text. The three margin annotations each gain a thin leader line to their step, which is the source's invisible same-rank placement made visible, with no arrowhead.
