%   cluster "Experience and channels" (slate band)    -> slate plane: Chat and UI, API clients,
%        Operator console (chips); the invisible placeholder e3 is not drawn

%   cluster "Gateways and integration / the only way out" (blue) -> blue plane (second phrase
%        set regular on the same title line): LLM Gateway, Tool Gateway, MCP . A2A, Egress proxy
%   cluster "Systems of record and providers / outside the trust boundary" (plum) -> plum plane:
%        Domain systems (cylinder), MCP servers, Partner agents, Model providers
%   cluster "Security and governance" (left spine, red) -> red rail, 7 chips: IdP . STS, Workload
