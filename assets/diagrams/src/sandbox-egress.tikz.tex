% nodes, labels, edges, edge styles and meaning are unchanged. Layout only is new:

% Original element -> restyled element

%   effect     Effect ledger / receipt or Unknown       -> plum card
%   refused    Refused / quarantined / reason + evidence -> red card
%   12 edges, same direction and labels (blue unless stated):

%     sandbox>refused "profile violation" (red)

%     credential>egress "scoped secret" (dashed)
%     dlp>endpoint "allowed"             dlp>refused "blocked / approval missing" (red)
%     endpoint>effect "external result"
